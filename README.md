# CodeAlpha Simple E-commerce Store

Full Stack Development - CodeAlpha Task 1.

## Required features implemented

- Product listings
- Product details page
- Shopping cart
- User registration/login
- Order processing
- Database storage for products, users and orders

## Technology

- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- SQLite

## Run locally

Requirements: Node.js 18+.

```bash
npm install
npm start
```

Open:

http://localhost:3000

The SQLite database is automatically created in the `data` folder on first run.
